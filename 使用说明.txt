【实时股价监控】使用说明 v9
============================

■ 系统要求
  · Windows 10 / Windows 11(自带 .NET Framework,无需安装)
  · 需要联网(行情来自腾讯/东方财富免费接口)

■ 快速使用
  1. 双击 StockMonitor.exe 运行(透明悬浮窗,置顶)
  2. 输入框输代码回车即添加并查看(A股自动识别沪/深/北;hk=港股,us=美股)
  3. 顶部下拉框切换自选股,全部自动刷新,无需手动查询
  4. 按钮:查询 / 配置 / 指标图 / 捐赠 / ×关闭

■ 捐赠
  · 点「捐赠」弹出支持界面,扫码即可(收款码内置在 exe 里)

■ 窗口操作
  · 拖动:按住窗口空白处拖动位置
  · 缩放:鼠标移到窗口边缘/四角拖拽调整大小,位置大小自动保存

■ 指标图显示方式(可在「配置 → 指标显示」切换)
  · 格子排列:指标图以自适应格子网格排布(默认,窗口越宽格子越多)
  · 行排列(叠放):每个指标整行叠放,经典行情软件样式
  · 两种方式都支持:悬浮看数值+十字线、点击放大

■ 主窗口布局
  · 顶部:分时主图(价格蓝线/均价黄线/昨收虚线/分钟MA叠加)
  · 下方:配置勾选的指标(分钟级):MACD / KDJ / RSI6 / BOLL / WR14 / BIAS6 / 量能
  · 悬浮:分时图显示 时间/价格/均价;指标图显示各线数值
  · 点击指标图:弹出大图(30/60/120/全部范围 + 说明)

■ 配置窗口
  [自选股]  按名称/代码搜索(如"茅台")一键添加
  [指标显示] 显示方式(格子/行)+ 勾选要显示的指标
  [提醒规则] KDJ_J≥100、RSI6≤20、价格≥1500、MACD_DIF上穿…
  [提醒方式] 全屏红光闪烁/秒数、提示音、刷新间隔

■ 指标速查
  MA(5/10/20)  均线,多头排列看涨
  MACD(12,26,9) DIF上穿DEA=金叉看涨,下穿=死叉看跌
  KDJ(9,3,3)    J>100超买,J<0超卖;K上穿D金叉
  RSI(6/12/24)  >70超买,<30超卖
  BOLL(20,2)    上/中/下轨
  WR14          >80超卖(反弹),<20超买(回调)
  BIAS(6/12)    偏离均线幅度

■ 分发
  · 复制 StockMonitor.exe 单个文件到其他电脑即可
  · 配置自动保存在 exe 同目录 config.json

■ 常见问题
  · SmartScreen:更多信息 → 仍要运行
  · 报错:exe 同目录 error.log,发给我排查
